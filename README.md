# 🚀 MERN Stack Developer Portfolio

A modern, fully responsive **Developer Portfolio** built with the **MERN Stack**. The portfolio includes a dedicated **Admin Panel** that allows content to be managed dynamically without editing the frontend code.

## ✨ Features

* 🎨 Modern and responsive UI built with **Tailwind CSS**
* ⚛️ Frontend built with **React.js**
* 🟢 Backend powered by **Node.js** and **Express.js**
* 🍃 **MongoDB** database for dynamic content storage
* 🔐 Admin Panel for managing portfolio content
* 📝 Dynamically update:

  * Personal information
  * About section
  * Skills
  * Projects
  * Experience
  * Education
  * Contact information
* 🖼️ Image upload and management using **Cloudinary**
* 🔄 Dynamic content updates without changing frontend code
* 🔗 RESTful API integration between frontend and backend

## 🛠️ Tech Stack

**Frontend:** React.js, Tailwind CSS
**Backend:** Node.js, Express.js
**Database:** MongoDB
**Media Storage:** Cloudinary

## 🔐 Admin Panel

The Admin Panel provides an easy way to manage portfolio content dynamically.

From the admin dashboard, you can add, edit, or delete:

* 👤 Profile and personal details
* 📝 About content
* 💻 Skills
* 🚀 Projects
* 💼 Experience
* 🎓 Education
* 📸 Project and profile images

All changes are stored in **MongoDB** and reflected dynamically on the portfolio.

## ☁️ Cloudinary Integration

Images are securely uploaded and managed using **Cloudinary**, allowing media files to be stored in the cloud instead of directly on the server.
